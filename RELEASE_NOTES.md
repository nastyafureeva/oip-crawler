# Release Notes

## Version 1.0.0

- Реализован краулер для скачивания HTML-страниц
- Добавлена проверка Content-Type
- Добавлены retry при ошибках сети
- Добавлена задержка между запросами
- Формируется index.txt
- Реализована возможность докачки

## Version 2.0.0

- Добавлена токенизация HTML-документов
- Удаляются дубликаты, числа и мусорные токены
- Удаляются союзы и предлоги
- Выполняется лемматизация с использованием pymorphy3
- Токены группируются по леммам
- Для каждой страницы создаются файлы:
  - tokens/<page>.txt
  - lemmas/<page>.txt


## Version 3.0.0

- Реализовано построение инвертированного индекса по леммам
- Индекс сохраняется в файл inverted_index.json
- Реализован булев поиск по индексу
- Поддерживаются операторы AND, OR, NOT
- Поддерживаются сложные запросы со скобками
- Запрос вводится строкой через аргументы командной строки

## Version 4.0.0

## Version 4.0.0

- Реализован расчет TF для терминов (токенов) как отношения числа вхождений термина к общему числу токенов документа
- Реализован расчет IDF для терминов по всей коллекции документов
- Реализован расчет TF-IDF для терминов
- Реализован расчет TF для лемм как суммы вхождений всех словоформ леммы, делённой на общее число токенов документа
- Реализован расчет IDF для лемм по всей коллекции документов
- Реализован расчет TF-IDF для лемм
- Для каждой страницы создаются файлы:
  - tfidf_tokens/<page>.txt
  - tfidf_lemmas/<page>.txt
- Каждая строка выходного файла имеет формат:
  - `<term> <idf> <tf-idf>`

  ## Version 5.0.0

- Реализована поисковая система на основе векторной модели
- Используются TF-IDF веса лемм из папки `tfidf_lemmas`
- Пользовательский запрос проходит токенизацию, очистку и лемматизацию
- Запрос преобразуется в TF-IDF вектор
- Для документов вычисляется косинусная мера сходства с вектором запроса
- Для ускорения поиска используются документы-кандидаты из `inverted_index.json`
- Реализован вывод наиболее релевантных документов
- Добавлен скрипт `vector_search.py` для выполнения векторного поиска
