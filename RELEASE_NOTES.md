# Release Notes

## Version 1.0.0

- Реализован краулер для скачивания HTML-страниц
- Добавлена проверка Content-Type
- Добавлены retry при ошибках сети
- Добавлена задержка между запросами
- Формируется index.txt
- Реализована возможность докачки

## Version 2.0.0

- Добавлена токенизация HTML-документов
- Удаляются дубликаты, числа и мусорные токены
- Удаляются союзы и предлоги
- Выполняется лемматизация с использованием pymorphy3
- Токены группируются по леммам
- Для каждой страницы создаются файлы:
  - tokens/<page>.txt
  - lemmas/<page>.txt


## Version 3.0.0

- Реализовано построение инвертированного индекса по леммам
- Индекс сохраняется в файл inverted_index.json
- Реализован булев поиск по индексу
- Поддерживаются операторы AND, OR, NOT
- Поддерживаются сложные запросы со скобками
- Запрос вводится строкой через аргументы командной строки
