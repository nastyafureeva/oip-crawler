## Задание 1

Краулер скачивает 100 HTML-страниц с сайта https://ilibrary.ru  
Страницы сохраняются вместе с HTML-разметкой (без очистки).

Для каждой страницы создаётся отдельный файл в папке `dump/`.

Также создаётся файл `index.txt`, содержащий соответствие:

имя_файла -> ссылка_на_страницу

## Задание 2

Из сохранённых HTML-документов выполнены:

1. Токенизация текста
2. Удаление:
   - дубликатов
   - союзов и предлогов
   - чисел
   - мусорных токенов (части разметки, слова с цифрами и т.д.)
3. Лемматизация токенов
4. Группировка токенов по леммам

Для каждой страницы создаются отдельные файлы:
out/
tokens/
*.txt # токены страницы
lemmas/
*.txt # леммы и соответствующие токены



## Используемые технологии

- Python 3
- requests
- beautifulsoup4
- pymorphy3

```bash
