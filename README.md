## Задание 1

Краулер скачивает 100 HTML-страниц с сайта https://ilibrary.ru.  
Страницы сохраняются вместе с HTML-разметкой (без очистки).

Для каждой страницы создаётся отдельный файл в папке `dump/`.

Также создаётся файл `index.txt`, содержащий соответствие:

имя_файла -> ссылка_на_страницу


## Задание 2

Из сохранённых HTML-документов выполняются:

1. Токенизация текста
2. Удаление:
   - дубликатов
   - союзов и предлогов
   - чисел
   - мусорных токенов (части разметки, слова с цифрами и т.д.)
3. Лемматизация токенов
4. Группировка токенов по леммам

Для каждой страницы создаются отдельные файлы:
out/
tokens/
*.txt # токены страницы
lemmas/
*.txt # леммы и соответствующие токены

## Задание 3

Реализован инвертированный индекс по леммам и булев поиск.

### Инвертированный индекс

На основе файлов из папки `out/lemmas` строится инвертированный индекс:


лемма -> список документов


Для каждой строки файла лемм используется первое слово (лемма).

Результат сохраняется в файл:


inverted_index.json


### Булев поиск

Реализован поиск по инвертированному индексу с поддержкой операторов:

- AND
- OR
- NOT

Поддерживаются сложные запросы со скобками.

Пример запроса:

```bash
python3 boolean_search.py -q "(клеопатра AND цезарь) OR помпей"
```
Запрос вводится строкой через аргументы командной строки.

## Задание 4

Для каждого скачанного документа (Задание 1) посчитаны:

- TF каждого **термина** (термины = токены из `out/tokens`)
- IDF для терминов по коллекции документов
- TF каждой **леммы** (лемматизированной формы) как сумму вхождений всех словоформ леммы, делённую на общее число токенов документа
- IDF для лемм по коллекции документов
- TF-IDF для терминов и лемм

### Входные данные

Ожидается, что после выполнения предыдущих заданий существуют:

- `out/tokens/` — файлы по документам, **один токен на строку**
- `out/lemmas/` — файлы по документам, строки формата: `<лемма> <словоформа>`

Имена файлов в `out/tokens` и `out/lemmas` должны совпадать (например `0001.txt`, `0002.txt`, ...).

После запуска будут созданы папки:

tfidf_tokens/ — tf-idf по терминам (токенам)
tfidf_lemmas/ — tf-idf по леммам

Каждый файл результата соответствует одному документу и содержит строки:

для терминов: <термин> <idf> <tf-idf>\n
для лемм: <лемма> <idf> <tf-idf>\n


## Задание 5

Реализована поисковая система на основе **векторного поиска** по построенному индексу.

Для поиска используются:
- леммы из `out/lemmas`
- инвертированный индекс `inverted_index.json`
- веса TF-IDF из папки `tfidf_lemmas`

Поисковый запрос:
1. разбивается на токены
2. нормализуется
3. очищается от стоп-слов и служебных частей речи
4. лемматизируется
5. преобразуется в вектор TF-IDF

Для каждого документа вычисляется степень близости к запросу с помощью **косинусной меры** между вектором запроса и вектором документа.

Чтобы ускорить поиск, сначала по `inverted_index.json` отбираются только документы-кандидаты, содержащие хотя бы одну лемму из запроса, и только по ним считается итоговая релевантность.

### Пример запуска

```bash
python3 vector_search.py -q "семья счастливая" --top 10
```
## Задание 6

В поисковую систему на основе векторного поиска добавлен **WEB-интерфейс**.

WEB-интерфейс позволяет:

1. ввести поисковый запрос через браузер
2. выполнить поиск по коллекции документов
3. выполнить **ранжирование** результатов по степени релевантности
4. вывести **top-10** наиболее релевантных документов

Для ранжирования используется векторная модель:
- запрос преобразуется в TF-IDF вектор
- для каждого документа вычисляется косинусная мера сходства с запросом
- документы сортируются по убыванию значения сходства

### Запуск

```bash
python3 app.py
```
После запуска интерфейс доступен в браузере по адресу:
http://127.0.0.1:5000
